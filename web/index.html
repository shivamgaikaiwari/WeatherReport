Weather Report

Search any city for current conditions and the week ahead.

About this project

Weather Report started as a native Android app written in Kotlin with Jetpack Compose. This page is a browser port of it, so you can try it without installing anything. Both versions call the free Open-Meteo API: a geocoding lookup turns the city name into coordinates, then a forecast request returns current conditions and seven days of highs and lows.

View the Kotlin source Download the Android app (APK)

Architecture

The Android app uses MVVM with one-way data flow. The web version keeps the same layers, one file each, so the two are easy to compare.

  1. ViewCompose WeatherScreen renders whatever state it is given and sends search events up.web: app.js
  2. ViewModelWeatherViewModel holds the query and a StateFlow of Idle, Loading, Success or Error, cancels stale searches, and turns exceptions into readable messages.web: viewmodel.js
  3. RepositoryWeatherRepositoryImpl chains the geocoding and forecast calls through Retrofit and returns a Result.web: repository.js
  4. MapperWeatherMapper converts Gson DTOs into domain models; WeatherCodeMapper turns WMO weather codes into text and icons.web: mapper.js

Dependencies are wired by hand in AppContainer, which keeps the ViewModel testable with a fake repository and no DI framework.

Tests

  • JsonParsingTest parses real-shaped geocoding and forecast fixtures with Gson.
  • WeatherMapperTest covers DTO-to-domain mapping and malformed data.
  • WeatherCodeMapperTest checks every WMO code group.
  • WeatherRepositoryImplTest runs Retrofit end to end against MockWebServer: success, city not found, HTTP 500 and bad JSON.
  • WeatherViewModelTest verifies state transitions and error messages with a test dispatcher.

The web port has its own tests for the mapper and ViewModel, run with Node's built-in test runner.
